### 🟣 Project 3 — Network Vulnerability Assessment – Nmap & Metasploit

<img src="https://img.shields.io/badge/Type-Network%20Security-9400D3?style=for-the-badge"/> <img src="https://img.shields.io/badge/Status-Completed-2ea44f?style=for-the-badge"/>

> Conducted a comprehensive **network vulnerability assessment** on **Metasploitable 2**, simulating a real-world enterprise environment with critical CVEs.

#### 🎯 What I Did
- 🌐 Performed **host discovery** and **1,000+ port scanning** across multiple systems to map the network attack surface using Nmap
- 🔍 Conducted **service enumeration** and **OS fingerprinting** to identify software versions, open ports, and running services
- 💣 Identified and manually exploited critical vulnerabilities including **CVE-2011-2523** using **Metasploit Framework** to gain root-level access
- 🔌 Performed manual exploitation using **Nmap scripts** and **Netcat** for service interaction
- 🔬 Analyzed live network traffic using **Wireshark** for packet-level evidence
- 📊 Scored all findings using **CVSS v3.1** and produced a **remediation-prioritized report** aligned to **PTES**

#### 🔬 Assessment Workflow
```
1. Host Discovery      →  nmap -sn <network_range>
2. Port Scanning       →  nmap -sV -sC -p- <target>
3. Service Enum        →  nmap --script vuln <target>
4. OS Fingerprinting   →  nmap -O <target>
5. Exploitation        →  msfconsole → search CVE-2011-2523 → exploit
6. Manual Exploitation →  Netcat for service interaction
7. Traffic Analysis    →  Wireshark packet capture
8. Risk Scoring        →  CVSS v3.1 Base Score Calculation
9. Reporting           →  Remediation-prioritized report (PTES-aligned)
```
