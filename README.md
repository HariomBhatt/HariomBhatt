### 🟣 Project 3 — Network Vulnerability Assessment Lab

<img src="https://img.shields.io/badge/Type-Network%20Security-9400D3?style=for-the-badge"/> <img src="https://img.shields.io/badge/Status-Completed-2ea44f?style=for-the-badge"/>

> Designed and executed a comprehensive **network vulnerability assessment** across a multi-host virtual lab environment simulating real enterprise infrastructure.

#### 🎯 What I Did
- 🌐 Performed **host discovery** and scanned **1,000+ ports** across multiple systems to map the network attack surface using Nmap
- 🔍 Conducted **service enumeration** to identify software versions, open ports, and running services
- 💣 Tested for exploitable vulnerabilities using the **Metasploit Framework** with controlled exploitation
- 📊 Scored all identified vulnerabilities using **CVSS v3.1** methodology to prioritize risk
- 📝 Produced a **remediation-prioritized vulnerability report** with mitigation strategies for each finding

#### 🔬 Assessment Workflow
```
1. Host Discovery      →  nmap -sn <network_range>
2. Port Scanning       →  nmap -sV -sC -p- <target>
3. Service Enum        →  nmap --script vuln <target>
4. Exploitation        →  msfconsole + search + use + exploit
5. Risk Scoring        →  CVSS v3.1 Base Score Calculation
6. Reporting           →  Vulnerability report with remediation
```
